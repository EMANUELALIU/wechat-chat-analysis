# 恋爱与人物关系分析 Skill

> **把聊天记录变成判断力。** 一个面向 AI 助手的 skill：喂给它你和某人的聊天记录（或让它帮你从微信导出），它输出人物画像、多人对比、矛盾识破、验真话术和 dating 日记。

## 它能帮你做什么

| 场景 | 你会得到什么 |
|---|---|
| 「帮我分析一下这个人」 | 八维人物画像：主动度/沟通风格/身份经济一致性/婚恋观/孩子观/边界感/契合度/风险，每条结论带聊天原文证据 |
| 「对比一下这几个男生」 | 横向对比表 + 人设类型归类 + 排序建议 + 下一步动作 |
| 「他是不是在骗我」 | **前后矛盾识别报告**：年龄/地点/职业/收入/资产/婚姻状态/多账号七类矛盾清单，逐条引用原话+时间戳 |
| 「我想试探他但怕唐突」 | 零攻击性验真话术（先交底自己→再引出对方） |
| 「怎么推进/怎么守底线」 | 约会推进方案、两周观察法、底线进度表 |
| 「帮我写成 dating 日记」 | 小红书文风的复盘日记 |

核心方法论只有两句，但都来自实战：

- **头衔和收入可以包装，但住哪、开什么车、怎么花小钱不会说谎。**
- **查户口式提问会吓跑人，"先说自己→再轻轻问"零攻击性，答案更真。**

## 内容结构

```

references/
  dating-playbook.md           恋爱分析完整内容结构（人设类型学/评分卡/矛盾识别法/信号表/话术库/模板）
  analysis-framework.md        通用八维框架与交叉验证原则
  export-playbook.md           微信聊天记录导出技术手册（Mac 微信 4.x，4.1.11 已验证）
scripts/
  setup.sh                     一键准备环境
  capture.sh                   抓取密钥脚本（自检+抓取+日志）
  diag_test.py                 lldb 附加自检模块
```

## 安装（1 分钟）

1. 把整个 `wechat-chat-analysis` 文件夹放进你所用平台的技能目录：
   - DSH：`~/.dsh/skills/wechat-chat-analysis/`
   - Claude Code：`~/.claude/skills/wechat-chat-analysis/`
   - Codex：`~/.codex/skills/wechat-chat-analysis/`
2. **新开一个对话**（技能目录在会话启动时加载），对 AI 说触发词即可：
   - 「分析一下这个人 / 对比这几个男生」
   - 「帮我看看和 XX 的聊天，他靠不靠谱」
   - 「帮我导出微信聊天记录」
   - 「写一篇 dating 日记」

## 环境要求

| 功能 | 要求 |
|---|---|
| 分析/对比/日记 | **任何设备均可**；直接贴聊天文本也能用，无需导出 |
| 导出微信记录 | Mac（Apple Silicon 已验证，微信 4.x 已登录）+ Xcode 命令行工具（lldb）+ 本机 sudo 密码 |

导出时需要：重签一次微信（仅影响本机调试权限，微信更新后需重做）、运行 `scripts/capture.sh` 时在微信里持续滚动聊天 90 秒。全程不联网、密钥仅存本机。

## 隐私与边界

- 只用于**你自己设备、自己账号**的数据。
- 分析建议仅供参考，最终决定永远由你自己做。
- 输出模板中的案例均为虚构演示，使用时请标注。
- 微信版本更新可能导致导出方法需要适配，请以当时 AI 的侦查结果为准。
